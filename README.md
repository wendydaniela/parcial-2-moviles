# Taller segundo corte moviles - bogotá conciertos <3

Aplicación móvil desarrollada con Flutter y Dart que implementa navegación por pestañas (`BottomNavigationBar`), componentes personalizados reutilizables y manejo de estado básico con `setState()`.

## Secciones de la App
- **Home:** Banner, carrusel horizontal y publicaciones con "Me gusta".
- **Chats:** Lista de conversaciones con componentes reutilizables (`ChatTile`).
- **Laboratorio:** Contador interactivo que actualiza variables numéricas mediante eventos.

1. Clona o descarga el repositorio.
2. Abre la terminal en la raíz del proyecto.
